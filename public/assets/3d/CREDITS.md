# Ícones 3D

Base: **3dicons**, de Vijay Verma (realvjy). Licença **CC0 1.0 Universal**, incluída em `LICENSE-CC0.txt`.

- Projeto original: https://github.com/realvjy/3dicons
- Metadados: https://github.com/realvjy/3dicons/tree/develop/content/3dicons-meta
- `about-computer.webp`: Computer, versão dynamic/clay.
- `projects-folder.webp`: Folder, versão dynamic/clay.
- `experience-notebook.webp`: Notebook, versão dynamic/clay.
- `contact-mail.webp`: Mail, versão dynamic/clay.
- `stack-cube.webp`: Cube, versão dynamic/clay, abaixo do título Stack.

Os renders originais foram adaptados para a paleta rosa do portfólio, preservando luz, sombra e transparência. Os arquivos locais têm 360×360px e foram convertidos para WebP. Não é necessário carregar scripts 3D ou acessar CDN para exibi-los.
